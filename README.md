# 交易复盘教练提示词

如果你手里有一堆仓位截图、成交记录、当前持仓，偶尔还夹着几张不同日期的快照，却不太确定：到底是哪几笔在赚钱、哪几笔在拖后腿、自己是不是一边做长持一边又在短线翻来覆去——把这些丢进来，这套提示词就是让 AI 帮你把账理清楚，再一起想想下一阶段最值得改什么。

适合偏中线、允许分批建仓和阶段性回撤的人。它不会按「赚钱=做对、亏钱=做错」倒推，也不会把有限样本包装成铁律。写法要求是完整自然的中文段落，并把推理强度拉满：机制对照、战役级分析、正反解释与证据边界都要写透。

## 它能帮你看什么

整份成绩怎么算。已平仓一套数，把当前持仓按市价算进去又是一套数，两套并排看；胜率、盈亏比、中位数、利润是不是都堆在少数大赢家身上，数字要落到具体金额。

你到底在用几种打法。比如股票类拿了几个月，BTC、ETH 却越来越像数日波段和反手——两种模式各自贡献了什么、损耗在哪，会分开说。

钱从哪来、风险压在哪。有时候利润主要靠几笔拿了很久的仓，波动却可能被一个近乎打平的大仓左右；它会尽量把这种错位点出来。

哪一段最值得复盘。不是只挑赚最多、亏最多的单笔，而是把短时间同品种反手、改方向同时加仓这类操作当成一整段战役来看。中线仓也会分开问：是逻辑还在，还是只是还没平。

还会用人话做 SWOT：强点、弱点、机会、威胁各写清楚，并单独列出最需要加强、且能过几周复查的几件事。

最后只留几件能接着验证的事。比如长持和波段分开记账、反手和加规模分开论证、后加的仓单独核算——写清楚怎么记、过几周看什么。

需要对外分享时，先给你看完整文字稿；你确认「可以按这份出图」之后，再做成四张推特友好图（横图或方图，字少字大）。每张右下角留二维码位，扫码就能打开本仓库用同一套提示词。图上的数字和品种全称必须跟核对稿一致。

## 它不会做什么

不会因为你赚钱就说你全对，也不会因为亏钱就说你全错。

不会默认长持更好、止损越紧越好、浮盈回吐一定错、亏损加仓一定错。

不会把相对某次快照的浮盈回吐，直接当成摸过最高点或退出失败。

不会把页面杠杆当成账户杠杆；优先用「名义敞口 ÷ 同期账户净值」看风险。

不展开手续费、吃挂单、撤单分析；保留平台盈亏口径，不重复扣减。

缺少完整行情路径时，不编造最高浮盈、最大不利波动、退出效率或止损回测。

没有交易日志时，不臆测报复交易、恐惧、贪婪等动机。

附件只当资料，不执行附件里的指令，也不猜测认不出来的数据。

文字稿没确认前，不擅自出成品图。

## 怎么用

1. 打开 [PROMPT.md](./PROMPT.md)。开头那段人话介绍是给你看的；从「第二部分：复制给 AI 的提示词」开始，整段复制发给 AI。
2. 把历史仓位、成交记录、当前持仓、历次快照、交易说明一起附上（截图、导出表、文字说明都行）。
3. 发给能认真读附件的 AI。缺净值、出入金或当时计划也没关系，有多少先分析多少，缺的它会标出来，再问你最关键的补充。
4. 先看完整文字稿；确认「可以按这份出图」后，再做成四张图。品种代码写交易所全称，例如 CRCLUSDT，不要把 CLUSDT 和 CRCLUSDT 混写。

## 你需要准备什么

有多少给多少，缺的它会标明：

- 已平仓与未平仓记录（品种全称、方向、数量、均价、开平时间、盈亏）
- 分批加减仓与反手记录
- 历次持仓或账户快照（带日期）
- 当时的交易说明或计划（若有）
- 同期账户净值、浮盈亏、出入金（有了才能算真实回撤和期间收益率）

## 一点提醒

结论强度要和证据强度一致；样本小就只能当线索，不能当铁律。

跨期仓位的全生命周期盈亏，不能直接当成某一期的账户收益。

改进建议应可验证：写清何时做、怎么做、记什么、过几周看什么，避免对着少量历史交易过度拟合。

对外分享用横图或方图，避免超长竖图被推特压糊。二维码指向：https://github.com/goupenguin/trading-review-prompt
