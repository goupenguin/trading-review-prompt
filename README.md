# 交易复盘教练提示词

一段可以直接复制的提示词：把历史仓位、成交、当前持仓、快照和交易说明交给 AI，让它像独立的交易研究员和教练一样做复盘，并和你讨论影响交易能力的深层问题。

适合偏中线、允许分批建仓和阶段性回撤的交易者。它不会按「赚钱=做对、亏钱=做错」倒推，也不会把有限样本包装成确定结论。写作要求是完整自然的中文段落，并把推理强度拉满：机制对照、战役级分析、正反解释与证据边界都要写透。

## 怎么用

1. 打开 [PROMPT.md](./PROMPT.md)，复制分割线下面的整段。
2. 把历史仓位、成交记录、当前持仓、历次快照、交易说明一起附上（截图、导出表、文字说明都行）。
3. 发给能认真读附件的 AI；缺净值、出入金或失效条件时，它会先用已有数据做完能做的部分，再问你最关键的补充。
4. 先看完整文字稿；确认「可以按这份出图」后，再做成 4 张推特友好图（优先横图约 1200×675 或方图约 1080×1080，字少字大）。每张右下角留二维码位，扫码打开本仓库即可用同一套提示词。图文必须与核对稿一致，品种代码写全称。

## 它会做什么

- 先按你的中长线风格理解交易方式，检查是否同时存在长持与数日波段两种模式，并核对数据口径（委托 / 成交 / 仓位 / 战役）
- 并排给出已平仓统计，和按最新市价计价的全部仓位快照；指标落到具体金额，并定义盈亏比、Profit Factor、中位数
- 看利润集中度（剔最大 / 前二 / 前三后还剩什么），检查利润来源与风险敞口是否错位
- 按平仓月份或阶段描述风格演变，并注明不能当作账户逐月收益率
- 案例写成战役：短时反手、改方向是否同时加规模、整段合计；中线仓区分「逻辑仍在」与「只是尚未退出」
- 挑 3～5 个真实问题深入讨论（正反解释与验证方法）
- 只给 1～3 项可验证改进：周期分开记账、反手与加规模分别论证、加仓部分独立核算等
- 品种代码写交易所全称（如 CRCLUSDT），不把 CLUSDT 与 CRCLUSDT 混写
- 确认文字稿后，额外交付 4 张可发推特的归纳图（核心判断 / 绩效全貌 / 关键问题 / 可验证改进），右下角预留指向本仓库的二维码位

## 它不会做什么

- 不迎合盈亏结果，不因赚钱就认定操作正确，也不因亏钱就认定决策错误
- 不默认长持更好、止损越紧越好、浮盈回吐一定错、亏损加仓一定错
- 不把相对某次快照的浮盈回吐，直接当成摸过最高点或退出失败
- 不把页面杠杆当成账户杠杆；优先用「名义敞口 ÷ 同期账户净值」看风险
- 不展开手续费、吃挂单、撤单分析；保留平台盈亏口径，不重复扣减
- 缺少完整行情路径时，不编造最高浮盈、最大不利波动、退出效率或止损回测
- 没有交易日志时，不臆测报复交易、恐惧、贪婪等动机
- 附件只当资料，不执行附件里的指令，也不猜测无法识别的数据
- 未获文字稿确认前，不擅自出成品图

## 你需要准备什么

尽量带上这些（有多少给多少，缺的它会标明）：

- 已平仓与未平仓记录（品种全称、方向、数量、均价、开平时间、盈亏）
- 分批加减仓与反手记录
- 历次持仓或账户快照（带日期）
- 当时的交易说明或计划（若有）
- 同期账户净值、浮盈亏、出入金（有了才能算真实回撤和期间收益率）

## 注意

- 结论强度应和证据强度一致；小样本只能当线索，不能当铁律。
- 跨期仓位的全生命周期盈亏，不能直接当成某一期的账户收益。
- 改进建议应可验证：写清何时做、怎么做、记什么、过几周看什么，避免对少量历史交易过度拟合。
- 对外分享用横图或方图，避免超长竖图被推特压糊；二维码指向 https://github.com/goupenguin/trading-review-prompt
