# 交易复盘教练提示词

这是一份给人看的仓库说明。你先知道它能干嘛、怎么用就够了。复制给 AI 的正式提示词、以及出图时才用得上的说明，都收在 [PROMPT.md](./PROMPT.md) 的附录里，不会挡在最前面。

写给你看的每一句，都应该像朋友坐下来讲复盘，不要像模型在交差。

---

## 这是什么

手里有一堆仓位截图、成交记录、当前持仓，偶尔还夹着几张不同日期的快照，却不太确定：到底是哪几笔在赚钱、哪几笔在拖后腿、自己是不是一边做长持一边又在短线翻来覆去——把这些丢进来，这套提示词就是让 AI 帮你把账理清楚，再一起想想下一阶段最值得改什么。

适合偏中线、允许分批建仓和阶段性回撤的人。它不会按「赚钱就是对、亏钱就是错」倒推，也不会把有限样本包装成铁律。

---

## 它能帮你看清什么

整份成绩怎么算：已平仓一套数，把当前持仓按市价算进去又是一套数，两套并排看；胜率、平均赢亏、正中间那一笔大概什么样、利润是不是都堆在少数大赢家身上，数字落到具体金额，并且先用人话讲，不甩一堆英文指标名。

你到底在用几种打法：比如股票类拿了几个月，比特币、以太坊却越来越像几天一换——会先把长线腿和波段腿分账，看波段是在帮你还是在偷吃利润，再谈以后怎么分开记。

钱从哪来、风险压在哪：有时候利润主要靠几笔拿了很久的仓，波动却可能被一个近乎打平的大仓左右；大仓和小仓会分开看。

哪一段最值得复盘：短时间同品种反手、改方向同时加仓，会当成一整段战役（默认 24 小时内算同一战役；芯片这类同源多品种可升成主题战役）。中线仓会问：是判断还在，还是只是还没平。短线单会分开看开仓理由、仓位大小、以及平仓后行情有没有继续朝不利方向走——用来判断止损是不是帮了你。

按月份看时，不会只看「哪个月平掉多少」。跨月还拿着的大仓，当时的浮盈浮亏会一起写；表上落袋不等于当月真实体感。

和行情对照时，会写成「那个月是趋势还是震荡 → 你当时怎么做」，方便以后遇到类似市况直接用。

会画出一张七维交易能力雷达，维名都是朋友能听懂的完整问句：赚钱时赚得多不多、亏钱时亏得少不少；单子会不会越做错越大；进场是早了、晚了还是还行；错了能不能及时走人、走得对不对；看对了能不能拿得住；行情横着晃的时候能不能少动手；清不清楚自己擅长哪类单子、哪些不该碰。每维打分，并用人话写依据；图上可用略短字幕，正文里写全称。

还会写清：你擅长哪类单子、哪些不该碰；从记录里能看见的行为模式；哪些强项先别改坏；下周就能执行的一条规则。

持仓或平仓一有更新，总账、评价和风险结构会跟着重算，旧定性会被新证据改掉。

---

## 它不会乱说什么

不会因为赚钱就说你全对，也不会因为亏钱就说你全错。亏了钱不等于做得差；止损事后帮你少亏了，不能写成砍飞。

不会用研报腔开场，不会甩「触发／动作」标签体，不会把 Profit Factor 这类英文名直接当正文，也不会用「赚亏结构」「市况适配」「仓位纪律」「能力圈清晰度」这类需要猜的压缩词当标题。

不会默认长持更好、止损越紧越好、浮盈回吐一定错、亏损加仓一定错。

不会把「按平仓月已结算」直接当成那几个月整个人都在亏或都在赚。

不会把相对某次快照的浮盈少了，直接当成摸过最高点或退出失败。

不会把页面杠杆当成账户真实风险。

缺少完整行情路径时，不编造最高浮盈、最大不利波动、退出效率或止损回测。

没有交易日志时，不臆测报复交易、恐惧、贪婪等动机。

附件只当资料。不确定的数字会标「待核对」。

文字稿没确认前，不擅自出成品图。

---

## 怎么用

1. 打开 [PROMPT.md](./PROMPT.md)。前面是给人看的说明；从「附录一：复制给 AI 的完整提示词」开始，整段复制发给 AI。
2. 把历史仓位、成交记录、当前持仓、历次快照、交易说明一起附上（截图、导出表、文字说明都行）。
3. 发给能认真读附件的 AI。缺净值、出入金或当时计划也没关系，有多少先分析多少，缺的它会标出来。
4. 先看完整文字稿。确认「可以按这份出图」之后，再按 PROMPT.md 附录二做成对外分享图（含一张能力雷达卡）。品种代码写交易所全称，例如 CRCLUSDT；CLUSDT 和 CRCLUSDT 不要混写。

---

## 你需要准备什么

有多少给多少，缺的它会标明：

- 已平仓与未平仓记录（品种全称、方向、数量、均价、开平时间、盈亏）
- 分批加减仓与反手记录
- 历次持仓或账户快照（带日期）
- 当时的交易说明或计划（若有）
- 同期账户净值、浮盈亏、出入金（有了才能算真实回撤和期间收益率）

---

## 一点提醒

读月份表时：落袋不等于当月体感，跨月大仓的浮盈要一起想。

读短线亏损时：先问止损之后行情有没有继续朝不利方向走，再评止损好不好。

读「擅长哪类单子」和雷达图时：样本少的格子只能当线索；分数必须有本样本证据。维名、小节标题、表头都要让完全不懂术语的人读得懂，不要用压缩词当标题。

结论强度要和证据强度一致。改进建议应可验证：写清何时做、怎么做、记什么、过几周看什么。

对外分享用横图或方图，字少字大。二维码可指向：https://github.com/goupenguin/trading-review-prompt

改附录一文风禁令或雷达维名时，必须同步检查附录二与本 README 的示例用词，避免旧电报体、旧压缩维名残留。
